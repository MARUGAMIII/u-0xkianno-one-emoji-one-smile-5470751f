One emoji — 🫶 (heart hands) — the single emoji most likely to make a stranger smile, written for make.fun's "One Emoji, One Smile" bounty. Two hands forming a small heart, sent straight to whoever is looking at the screen: warm at first glance, universal across ages and backgrounds, clearly chosen rather than the first default smiley, and friendly goodwill from a stranger rather than romance or flirtation.

The entry program writes that single emoji to `/output/entry.txt` — one character, UTF-8 — and reads it back to verify exactly one emoji was written.

## Run it

